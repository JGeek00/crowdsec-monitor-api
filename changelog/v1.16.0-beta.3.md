# v1.16.0-beta.3

## New

- Filter by date range: when listing attacks or blocking decisions, you can now ask for only what happened during a specific period — just a starting moment, just an ending moment, or both. Handy for answering questions like "what happened last weekend?" without scrolling through everything.
- This works everywhere the lists are shown: through the API and also when you ask your AI assistant for your attack history.

## Notes

- Dates and times for these filters are always read in the UTC time zone, so results are the same no matter where the server lives.
- No configuration or stored data changes. Updating is safe and requires no manual action: just update the API and keep your current settings.
