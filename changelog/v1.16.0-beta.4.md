# v1.16.0-beta.4

## Changed

- Cleaner console logs for the AI assistant endpoint: the API no longer prints one raw HTTP line per MCP request (they only said someone was connected, not what they did). Instead, every assistant action is now logged with the name of the tool it ran, e.g. `[mcp] tool: 'get_alerts_stats'`, so the console shows what the assistant actually asked for.
- Internal modernization: updated build tooling (pnpm 12, TypeScript 6, faster dev server). Nothing visible changes for you.

## Notes

- No configuration or stored data changes. Updating is safe and requires no manual action: just update the API and keep your current settings.
