# v1.15.0-beta.5

## Improved

- Alert details in notifications are now easier to read: the summary and alert tables have a light gray border around every cell, and each event table is clearly separated from the next one instead of appearing as one dense block.

## Notes

- This release only affects the look of notifications that include alert information. Existing notifications keep working exactly as before.
- This is a beta release: notification behavior may still be refined before the final release.
