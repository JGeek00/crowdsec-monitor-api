# v1.16.1

## Fixed

- Refreshing a single blocklist could fail right at the end — after the IPs were already imported — with a cryptic error and leave the refresh status unrecorded. The result of the refresh (successful or failed, with its date) is now always saved correctly, so the app shows the true state of each list.
- The error message above was unreadable (something like `_0x... is not a function`) because the production build obfuscated the code. Errors in the logs now show the real names and locations, which makes diagnosing any future problem much faster.

## Changed

- The production build no longer obfuscates the code — this project is open source, so there is nothing to hide and readable logs are worth more than obfuscation. There is now a single `pnpm build` command instead of separate dev and production builds.

## Notes

- No configuration or stored data changes. Updating is safe and requires no manual action: just update the API and keep your current settings.
