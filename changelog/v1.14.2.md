# v1.14.2

## Fixed

- Fixed an issue where the API Docker container was reported as `unhealthy` after upgrading to v1.14.1, even though the API was running correctly. The container health check relied on `wget`, which is no longer available in the new Docker base image.
- The health check no longer depends on any external tool: it now uses Node.js' built-in `fetch`, so it works out of the box and the container is correctly reported as `healthy` again.
- No action is required to apply the fix: just pull the new image and recreate the container. Existing configuration, environment variables and volumes remain unchanged.
