# v1.16.0-beta.1

## Changed

- This release focuses on the server's internal foundations. The code has been reorganized into clearly separated layers (web interface, business rules, data access), which makes future features faster to build and easier to review. Everything works exactly as before: no endpoint, setting, or behavior has changed.
- Quality guardrails: the server is now backed by a comprehensive automated test suite (more than 1,100 checks covering the web endpoints, the database layer, the scheduler, and the configuration), so regressions are caught automatically before they reach a release.

## Fixed

- General statistics now always deliver their numbers under the correct field names for countries, organizations, scenarios, and targets, so the mobile apps can read and display them reliably.

## Notes

- This beta includes no new features; it is a preparation release for the upcoming v1.16.0 features.
- No configuration or stored data changes. Updating is safe and requires no manual action: just update the API and keep your current settings.
