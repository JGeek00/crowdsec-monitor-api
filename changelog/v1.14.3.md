# v1.14.3

## Changed

- All dates and times provided by the API (alerts, decisions and status information) now use one single, standard international format expressed in UTC.
- Until now, timestamps followed a confusing custom layout in which the time zone appeared twice and the values could look different depending on where your CrowdSec server was located or how its time zone was configured (for example, `2026-09-24 16:19:29 +0200 +0200`). They now always use the widely adopted standard format (for example, `2026-09-24T14:19:29Z`).
- With the new format, times are unambiguous no matter which server generated them, and the mobile apps display them consistently, converting them to your local time.
- Previously synced data is converted automatically, so nothing is lost and no manual action is required on your existing information.

## Notes

- Make sure you are running the latest versions of the mobile apps: older app versions expect the previous time format and may not display times correctly with this API version.
