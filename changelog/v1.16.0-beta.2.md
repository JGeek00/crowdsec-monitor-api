# v1.16.0-beta.2

## New

- AI assistant integration: the server can now talk directly to AI assistants (such as Claude) through the Model Context Protocol (MCP). Point your assistant at this server and you can ask things like "how many attacks did I get this week?", "is this IP address blocked anywhere?" or "show me the latest decisions" in plain language, without using the API by hand.
- IP lookup for assistants: your assistant can check whether any IPv4 or IPv6 address appears in your blocklists or allowlists and tell you which lists contain it.
- Everything the assistant can see or do goes through the same rules as the apps: if you set an API password, the assistant needs it too; if you didn't, it just works.

## Changed

- New optional `MCP_RATE_LIMIT` setting: if you want to limit how often assistants (or anyone) can query the MCP endpoint, you can now set a separate limit for it, independent from the one that protects the app API. Left empty, there is no limit — exactly like before.

## Notes

- This is a beta: the assistant integration is new and feedback is welcome, but your data and settings are untouched.
- No configuration or stored data changes. Updating is safe and requires no manual action: just update the API and keep your current settings.
